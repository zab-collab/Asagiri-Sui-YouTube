# 朝霧すい - YouTube

スマートフォンで確認できる、朝霧すいの初期ページです。

## GitHub Pagesで公開する
1. リポジトリの「Add file」→「Upload files」を選びます。
2. ZIPを端末内で解凍し、中の `index.html` と `README.md` をアップロードします（ZIP自体をアップロードするだけでは公開ページになりません）。
3. 変更をコミットします。
4. Settings → Pages で公開元を `Deploy from a branch`、ブランチを `main`、フォルダーを `/(root)` に設定します。

## 現時点の機能
- 朝霧すいの仮アバター表示
- 入力メッセージの表示
- ブラウザーの日本語音声読み上げ
